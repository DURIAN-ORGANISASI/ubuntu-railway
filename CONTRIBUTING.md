# Panduan kontribusi

Kontribusi untuk Ubuntu Personal Railway dipersilakan melalui Issues dan Pull Requests.

## Sebelum mengajukan perubahan

- Jelaskan masalah dan perubahan yang ingin dibuat.
- Jika mengubah image, pastikan Docker build berhasil.
- Periksa apakah README Indonesia dan Inggris serta dokumentasi sumber perlu diperbarui.
- Jangan menyatakan tes Railway live telah berhasil jika hanya menjalankan tes lokal.

## Keamanan

Jangan commit password, API key, token, file environment berisi rahasia, atau log autentikasi. Pertahankan validasi kredensial, pemeriksaan Origin, dan penekanan log ttyd yang dimaksudkan untuk mengurangi risiko pengungkapan kredensial.
